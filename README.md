# 🔍 Clone da Página Inicial do Google

Projeto inspirado na página inicial do Google, desenvolvido com HTML e CSS.  
O objetivo foi recriar a interface minimalista do buscador mais utilizado do mundo, praticando alinhamento, responsividade e estilização moderna.

---

## 📸 Preview

### Página Principal
- Logo centralizada
- Barra de pesquisa estilizada
- Botões personalizados
- Layout minimalista
- Ícones e navegação inspirados no Google

---

## 🚀 Tecnologias Utilizadas

- HTML5
- CSS3
- Flexbox
- Responsividade
- Design Minimalista
